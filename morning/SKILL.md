# Morning

Read [TASKS.md](TASKS.md) fresh each run and carry out every enabled task. Checked items are enabled; unchecked items are paused. Leave the checkboxes unchanged after execution.

Use the scripts, skills, and workspace instructions each task references. Keep progress in the chat: pending, running, done, blocked, or waiting for the user. If one task fails or needs an answer, continue the other independent tasks and report what happened. On resumption, check this chat's results before repeating completed work.

Finish with a compact result for each task, including failures and any questions that need the user's attention. Preserve any referenced skill's rules about keeping results ephemeral.

When asked to add or change a chore, edit TASKS.md in plain English. Use existing tools and scripts; adding a task should not require a new runner, database, or scheduled job.
