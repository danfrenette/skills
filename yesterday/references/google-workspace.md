# Google Workspace

Run each section whose tools exist. Calendar and Gmail can be available separately.

## Google Calendar

Google Calendar is the schedule of record. List the user's events in the reporting window to
establish which meetings happened and who attended. Keep events the user accepted or organized; a
declined event did not happen for the user. Record focus blocks only when they explain untracked
work.

## Gmail

Search mail the user sent in the window. Gmail search accepts Unix seconds, which avoids timezone
drift: `in:sent after:<window start> before:<window end>`. Read the threads behind those messages
when they concern work: replies to customers, vendors, or colleagues that show progress, decisions,
or blockers.

Leave notification mail from Linear, GitHub, Slack, and calendars to those sources. Summarize a
thread in one line; the brief reports work, not correspondence.

Done when every kept meeting has its attendees and every work thread has a one-line summary.
