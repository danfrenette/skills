# Inspect a visual reference

Before building from a supplied example, inspect the exact interactive surface. Check whether
sign-in or a linked full version changes what is visible. Use the user's authenticated session when
necessary; use an isolated browser for the resulting implementation checks.

Exercise the relevant interaction and record observed behavior separately from inferred
implementation. If the reference remains inaccessible, name the uncertainty and continue only work
that does not depend on it. Apply this recon before handing the brief to an installed prototype
skill; keep downloaded skill dependencies unchanged.

**Done:** the brief identifies the inspected reference and observed interactions, or explicitly
identifies the unavailable evidence and which independent work can proceed.
